# 바치올 주가 실험실 · 고객 배포 자료

AI 코딩 도구에 순서대로 입력해 국내주식 조회 프로그램을 만드는 안내서와 프롬프트입니다. 완성된 프로그램 설치 파일은 아닙니다.

## 다운로드와 시작

1. [고객 배포 ZIP 다운로드](./바치올_주가실험실_고객배포용.zip?raw=true)를 눌러 압축 파일을 받습니다.
2. 압축을 풀고 `01_시작안내.txt`를 읽습니다.
3. `03_복사해서사용.html`을 브라우저로 열어 0~6번 프롬프트를 순서대로 복사합니다.

GitHub에서 바로 보려면 [시작 안내](./고객배포용/01_시작안내.txt), [전체 프롬프트](./고객배포용/02_전체프롬프트.md)를 이용하세요.

## 자료 구성

- 시작 안내: 준비 사항, 키 설정, 실행 방법
- 전체 프롬프트: 0~6단계 전체 내용
- 복사해서 사용: 단계별 복사 버튼이 있는 HTML 파일
- 단계별 프롬프트: 단계별 TXT 파일 7개

## 이용 안내

API 키는 본인 PC의 `.env.local`에만 저장하고 GitHub나 AI 대화에 올리지 마세요. 키 없이도 0~1단계의 예시 화면은 만들 수 있습니다.

생성 결과는 사용 환경에 따라 달라지며, 실제 API 연결과 데이터 검증이 필요합니다. 이 자료는 특정 종목의 매수·매도를 권유하지 않습니다. 워런 버핏·버크셔 해서웨이의 공식 도구가 아닙니다.
