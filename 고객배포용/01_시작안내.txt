바치올 주가 실험실 | 고객용 시작 안내

이 자료는 AI 코딩 도구에 순서대로 입력해 국내주식 조회 프로그램을 만드는 안내서입니다. 완성 프로그램 설치 파일은 아닙니다. 생성 결과는 사용 환경에 따라 달라지며, 실제 데이터 검증까지 진행해야 합니다.

1. 준비하기
• 현재 지원 중인 Node.js LTS, 로컬 폴더를 열어 파일을 만들 수 있는 AI 코딩 도구를 준비합니다.
• KB증권 Open API 이용 신청 및 APP KEY·APP SECRET, 금융감독원 OpenDART 인증키를 준비합니다. 발급·이용 조건은 각 공식 사이트에서 확인합니다.
• 바탕화면 등에 새 폴더를 만들고 해당 폴더를 AI 코딩 도구에서 엽니다.
• 키가 없어도 0~1번의 규칙과 예시 화면은 만들 수 있습니다. 실제 시세에는 KB 키, 공시 재무에는 OpenDART 키가 필요합니다.

2. 키 설정하기
새 프로젝트 폴더에 .env.local 파일을 만들고 아래 세 줄의 오른쪽 값만 본인의 키로 바꿉니다.

KB_APP_KEY=여기에_본인_APP_KEY
KB_APP_SECRET=여기에_본인_APP_SECRET
OPENDART_API_KEY=여기에_본인_OPENDART_키

Windows 메모장에서 저장할 때 파일 형식은 모든 파일, 파일명은 .env.local로 지정합니다. .env.local.txt가 아닌지 확인합니다. 키는 AI 대화·화면 캡처·공유 문서에 붙여 넣지 않습니다. 이 파일은 본인 프로젝트 폴더에만 보관하고 배포 ZIP에 넣지 않습니다. 노출됐다면 해당 발급기관에서 폐기·재발급합니다.

3. 입력 순서
02_전체프롬프트.md의 코드 블록 또는 단계별_프롬프트 폴더의 TXT 전체를 복사합니다. 03_복사해서사용.html을 브라우저로 열면 단계별 복사 버튼을 사용할 수 있습니다.

0번: 공통 규칙 저장 → AGENTS.md 생성 확인. 아직 화면이 없는 것이 정상입니다.
1번: 예시 화면 제작 → 샘플 데이터 표시와 다섯 질문 카드 확인.
2번: 실제 시세 연결 → 종목코드로 조회하고 출처·조회 시각 확인.
3번: 이름 검색·공시 재무 → 같은 회사인지, 재무 출처·기준연도 확인.
4번: 다섯 질문 계산 → 계산 근거·자료 부족·가격 수치 표시 확인.
5번: 실제 종목 검증 → 두 종목의 원본 데이터 대조와 오류 재검증.
6번: 최종 점검 → 화면·보안·표현 검사 결과와 미확인 사항 확인.

4. 실행하기
1번 이후 AI에게 “프로그램을 실행해 줘”라고 요청하거나 프로젝트 폴더의 터미널에서 node server.mjs를 실행합니다. 같은 PC의 브라우저에서 http://127.0.0.1:4318 을 엽니다. 직접 실행한 터미널에서는 Ctrl+C로 종료합니다. AI가 실행했다면 AI에게 종료를 요청합니다.
이 주소는 본인 PC용입니다. 휴대폰 화면 검증은 PC 브라우저의 화면 폭을 390px로 바꾸어 진행합니다. 외부 공유·클라우드 배포는 이 안내 범위에 포함하지 않습니다.

5. 결과를 읽는 방법
• 안정적으로 확인됨: 이 도구의 해당 숫자 조건을 충족했다는 뜻입니다. 투자 안전성이나 미래 성과를 보장하지 않습니다.
• 추가 확인 필요: 변동·주의점 또는 일반기업 기준을 적용하기 어려운 사유가 있습니다.
• 자료 부족: 필요한 값이나 비교 기준이 충분히 확인되지 않았습니다.
• 수치 확인: 가격 관련 숫자를 확인했다는 뜻이며 저평가·고평가 판단이 아닙니다.
시세와 공시의 기준 시점은 다릅니다. 증권사 앱과 비교할 때도 시장·시점·지연 여부를 함께 확인합니다. 장이 끝났다는 이유로 등락률을 임의로 0으로 바꾸지 않습니다.

6. 막혔을 때 복사할 문장
“현재 단계는 __번입니다. __를 입력했을 때 __ 문제가 나옵니다. 원인을 확인하고 수정한 다음 같은 조건으로 다시 검증해 주세요. 없는 숫자를 임의로 채우지 말고, 키·토큰은 출력하지 마세요. 실행하지 못한 검사는 미확인으로 알려 주세요.”
공식 API 문서를 도구가 읽지 못하면 해당 API의 공식 문서나 JSON·Excel 자료를 제공합니다. 인증정보가 포함된 요청 URL·로그 전체는 공유하지 않습니다.
