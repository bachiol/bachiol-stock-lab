로컬 사용 전 최종 점검을 해줘. 고칠 것이 있으면 고치고, 항목별로 확인 결과를 알려줘.

[모바일]
- 390px 폭에서 가로 스크롤이나 잘린 항목이 없는지, 현재가 카드·요약·다섯 질문 카드가 한 열로 읽히는지 확인해줘.
- 조회 중, 자료 부족, 조회 실패 상태가 각각 화면에 제대로 안내되는지 확인해줘.
- 하단 고정 띠가 마지막 내용을 가리지 않는지 확인해줘.

[보안]
- 실제 키와 시크릿이 소스코드, Git 기록, 공개 파일에 없는지 확인해줘. 변수 이름만 있어야 한다.
- 브라우저가 받는 /api 응답에 키, 토큰, IP, MAC, KB 원본 응답 전체가 없는지 확인해줘.
- 일부러 오류를 내 보고(잘못된 종목코드, 인증 실패 가정) 오류 메시지와 서버 로그에 비밀값이 나오지 않는지 확인해줘.
- .env.local과 캐시 폴더가 웹 주소로 열리지 않는지(404) 확인해줘.
- 서버가 조회 API만 호출하고 계좌·잔고·주문·정정·취소 API를 호출하지 않는지 확인해줘.

[표현]
- 화면에 종합 점수, 목표주가, 저평가·고평가 판정, 특정 종목을 사거나 팔라고 권하는 문장이 없는지 확인해줘. 하단 고정 띠와 요약 아래 안내문의 "매수 또는 매도를 권유하지 않습니다", "매수·매도 판단이 아닙니다"는 권유가 아니라는 안내이므로 그대로 둔다.
- KB증권 제공값과 OpenDART 값의 출처가 모든 카드에서 구분되어 있는지 확인해줘.

확인은 키 값을 다시 보여주는 방식이 아니라 실제 시세 조회와 "설정됨/설정되지 않음" 상태로 해줘.
- 실제 인증값을 변경해 오류를 만들지 말고 가상 응답으로 인증 실패를 재현한다. Git 저장소가 없으면 기록 검사는 해당 없음으로 보고한다.
- 390px 검증은 PC 브라우저의 화면 폭 변경으로 진행한다. 127.0.0.1로만 실행하므로 별도 휴대폰에서 접속하도록 서버를 공개하지 않는다.
- 결과는 통과 / 수정 후 통과 / 미확인 / 해당 없음으로 구분하고, 실행한 검사와 남은 문제를 적는다. 정적 확인만 한 항목을 실제 동작 확인으로 보고하지 않는다.
- README에 실행·종료·재실행 방법과 필요한 설정 이름, 지원 범위, 데이터 한계를 정리한다. 실제 비밀값은 넣지 않는다.
