국내 상장종목을 검색해 기업의 기본 정보와 재무 상태를 확인하는 반응형 웹사이트의 첫 화면을 만들어줘. 아직 실제 API는 연결하지 말고 예시 데이터로 구성하고, 화면에 "샘플 데이터"라고 표시해줘.

[파일]
- server.mjs, public/index.html, public/styles.css, public/app.js
- node server.mjs로 실행하면 http://127.0.0.1:4318 에서 열린다.

[화면 구성 — 위에서 아래로]
1. 머리말: 서비스명 "바치올 주가 실험실", 제목 "워런 버핏이라면 기업을 볼 때 어떤 숫자를 먼저 확인할까?", 설명 "공개적으로 알려진 그의 투자 관점을 다섯 가지 질문으로 정리했습니다. 시세와 공시에서 사실을 확인하고, 판단은 보는 사람에게 남깁니다."
2. 검색 영역: 회사명·종목코드·자연어를 입력하는 검색창, 후보 목록, "선택 종목 조회" 버튼.
3. 현재가 카드: 종목명, 종목코드, 현재가(원), 전일 대비와 등락률, 시가·고가·저가, 거래량, 시가총액, 52주 최저~최고, 외국인 보유비중, 시장구분·지수, 출처, 조회 완료 시각.
4. "다섯 질문 확인 결과" 요약: 질문 하나가 한 줄(질문 이름 · 상태 · 한 문장 설명). 종합 점수나 결론은 없다.
5. 다섯 장의 질문 카드. 번호(01~05)와 제목은 다음과 같다.
   01 꾸준히 돈을 버는가? / 02 자본을 효율적으로 쓰는가? / 03 부채를 감당할 수 있는가? / 04 현금이 실제로 남는가? / 05 현재 가격이 부담스럽지 않은가?
   각 카드에는 핵심 숫자 묶음, 출처·기준 기간 한 줄, "버핏이라면 여기서 무엇을 봤을까"라는 해석 칸(버핏의 관점 한 줄 + 이 회사의 숫자 한 문단)과 상태 표시, 접을 수 있는 칸 세 개(최근 5년 재무 추이 / 원본·공시 근거 / 계산 방법과 해석의 한계)가 들어간다.
   숫자마다 "공시 확인", "계산 확인", "KB 제공" 중 하나의 작은 표시를 붙인다.
6. 화면 맨 아래 고정 띠: 굵게 "좋은 기업인가? 그리고 지금 가격도 좋은가?", 옆에 작게 "정보 제공 목적이며 특정 종목의 매수 또는 매도를 권유하지 않습니다. 모든 투자 판단과 책임은 투자자 본인에게 있습니다. 워런 버핏·버크셔 해서웨이의 공식 도구가 아닙니다."

[레이아웃]
- 16:9 PC 화면에서 머리말과 검색 영역이 2열로 나란히 놓이고, 그 아래 현재가 카드와 요약, 질문 카드가 전체 폭으로 이어진다.
- 390px 모바일에서는 가로 스크롤 없이 한 열로 재배치된다.
- 하단 고정 띠가 내용을 가리지 않게 아래 여백을 둔다.
- 차분한 남색 계열, 번호 배지는 작은 정사각형 안에 숫자가 정확히 들어가게 한다.

종합점수나 매수·매도 표현은 쓰지 마. 완성되면 실행 방법을 알려줘.
- 실제 API로 전환한 영역에서는 샘플 값을 완전히 제거한다. 아직 샘플인 영역은 영역별로 샘플 데이터 표시를 유지한다. 조회 실패 시 샘플 값으로 되돌리지 않는다.
