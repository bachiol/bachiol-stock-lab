이 폴더에 "바치올 주가 실험실"이라는 로컬 웹 프로그램을 단계별로 만들 거야. 먼저 아래 공통 규칙을 AGENTS.md 파일로 저장하고, 앞으로 모든 작업에서 지켜줘. 이번에는 AGENTS.md만 만들고 다른 코드는 작성하지 마.

[프로그램의 성격]
- 국내 상장종목 하나를 조회해, 공개적으로 알려진 워런 버핏의 투자 관점을 다섯 가지 질문으로 정리해 보여주는 기업 정보 확인 도구다.
- 투자 추천 도구가 아니다. 종합 점수, 등급, 매수·매도 의견, 목표주가, "싸다/비싸다" 같은 판정을 화면에 만들지 않는다.
- 워런 버핏이나 버크셔 해서웨이의 공식 도구·공식 기준이 아니라는 점을 화면에 밝힌다.

[기술 조건]
- 현재 지원 중인 Node.js LTS를 사용한다. 우선 내장 모듈로 구현하되, ZIP·XML 처리를 직접 구현하기 어려우면 유지보수되는 최소 의존성을 사용하고 용도와 버전 및 잠금 파일을 남긴다.
- server.mjs가 127.0.0.1의 4318 포트에서만 열리고, public 폴더의 지정한 파일만 제공한다.
- 브라우저는 우리 서버의 /api/... 만 호출한다. 외부 API는 서버에서만 호출한다.

[인증 정보]
- 폴더의 .env.local에서 KB_APP_KEY, KB_APP_SECRET, OPENDART_API_KEY를 서버가 읽는다. 값을 새로 만들거나 바꾸지 않는다.
- 키, 시크릿, 접근 토큰, IP, MAC 주소를 답변, 소스코드, 브라우저 응답, 로그, 오류 메시지, 테스트 출력에 절대 표시하지 않는다. 설정 여부는 "설정됨/설정되지 않음"으로만 말한다.
- .env.local과 캐시 폴더는 .gitignore에 넣고 웹으로 제공하지 않는다.

[데이터 원칙]
- 시세·종목 정보는 KB증권 Open API, 다년 재무·현금흐름은 금융감독원 OpenDART에서 가져온다. 화면에서 두 출처를 항상 구분해 표시한다.
- 확인되지 않은 값은 추정하거나 0으로 채우지 않고 "자료 부족" 또는 "확인 불가"로 표시한다. 한 출처가 실패해도 다른 출처의 값을 대신 쓰지 않는다.
- 공식 문서에서 확인되지 않은 주소, 요청값, 응답 항목을 추측하지 않는다. 가격을 사전 지식으로 채우지 않는다.
- 조회 전용이다. 계좌, 잔고, 주문, 정정, 취소 API는 연결하지 않는다.
- 공시 총액은 원 단위 정수(BigInt)로 보존한다. EPS·BPS·비율처럼 소수가 있는 값은 정밀도를 보존한다. 나눗셈은 분자·분모 또는 고정소수점으로 처리해 중간 정수 절삭을 피하고 표시할 때만 반올림한다. JSON에서는 BigInt를 문자열로 전달한다.

[표시 원칙]
- 금액은 "11조 3,145억 원"처럼 조·억 단위로 표시한다(억 미만 반올림). 비율은 소수 둘째 자리까지.
- 질문 01~04의 상태 문구는 "안정적으로 확인됨", "추가 확인 필요", "자료 부족"만 쓴다. 가격 질문(05)만 값이 확인되면 "수치 확인", 없으면 "자료 부족"을 쓴다. 가격에는 "안정적"이라는 말을 붙이지 않는다.
- "자료 부족"은 필요한 숫자가 없어 판단할 수 없을 때, "추가 확인 필요"는 숫자는 있는데 변동이나 주의점이 있을 때 쓴다. 둘을 섞지 않는다. 필요한 숫자가 하나라도 없으면 "안정적으로 확인됨"을 쓰지 않는다.
- 해석 문장에 회사명을 넣지 않고 "이 회사"라고 쓴다.

[작업 방식]
- 파싱·계산·오류 처리·비밀값 비노출에 필요한 테스트를 tests 폴더에 작성하고 node --test로 실행한다. 자동 테스트에는 가상 응답을 사용하고, 실제 API 검증은 별도로 수행한다. 실행하지 못한 검증은 미확인으로 보고한다.
- 작업이 끝나면 무엇을 만들었는지, 어떻게 실행하는지, 무엇을 확인하지 못했는지를 짧게 알려준다.
- 기존 AGENTS.md가 있으면 덮어쓰지 말고 충돌 여부를 확인해 병합한다.
- 이 작업은 고객 PC에서 실행할 로컬 프로그램 제작이다. 외부 공개, 터널링, 클라우드 배포를 자동으로 하지 않는다. 4318 포트가 사용 중이면 다른 프로세스를 종료하지 말고 원인을 알린다.
- 브라우저로 제공할 파일은 명시적으로 허용하고, API의 Host·Origin을 검증한다. 외부 사이트의 호출을 허용하는 CORS 설정을 넣지 않는다.
- .env.local의 내용을 화면이나 도구 출력으로 읽어 보여주지 않는다. 서버에서 읽고 설정 상태만 확인한다. 캐시에는 인증정보와 인증정보가 포함된 URL을 저장하지 않는다.
