예시 시세를 제거하고 KB증권 Open API로 국내주식 시세를 서버에서 연결해줘. 인증정보는 .env.local의 KB_APP_KEY, KB_APP_SECRET을 서버에서만 읽어줘.

[공식 문서부터 확인]
- https://openapi.kbsec.com/apidoc_b2c 의 최신 공식 문서에서 인증과 국내주식 현재가·기업개요 조회 규격을 확인한다.
- 호스트, 포트, 경로, HTTP 메서드, 헤더, 요청 본문, 성공·오류 코드, 응답 필드, 단위, 호출 제한을 확인한 뒤 구현한다. 확인한 문서와 확인일, 사용하는 항목을 API_MAPPING.md에 기록한다. 인증정보나 인증정보가 들어 있는 요청 URL은 기록하지 않는다.
- 공식 문서를 읽을 수 없으면 사용자에게 해당 API의 문서 또는 공식 JSON·Excel 자료를 요청한다. 주소·필드·성공 코드를 추측하거나 이전 구현의 값을 검증 없이 사용하지 않는다.
- IP·MAC 등 추가 정보가 필요한지는 공식 규격에서 확인한다. 네트워크 구성을 임의로 변경하지 않고 값은 출력하지 않는다.

[연결과 값 처리]
- 인증 토큰은 서버 메모리에만 보관한다. 만료·재발급은 공식 규격에 맞추고 무한 재시도하지 않는다.
- 확정된 6자리 종목코드만 KB에 전달한다. 종목명이나 자연어는 전달하지 않는다.
- 현재가, 전일종가, 등락률, 시가·고가·저가, 거래량, 시가총액, 시장구분·지수, 52주 범위와 기업개요 지표는 공식 응답에서 확인되는 항목만 표시한다.
- 공백·선행 0·부호·소수점은 공식 형식에 맞게 파싱한다. 빈 문자열·누락·잘못된 형식은 0으로 바꾸지 않는다. 현재가는 양의 값인지 확인한다.
- 시가총액 단위는 공식 문서로 확인하고 원 단위로 변환한다. 현재가×상장주식수 비교는 보조 검증으로만 사용하며, 불일치 시 시점·주식수 범위를 확인한다. 비슷한 숫자가 나온다는 이유만으로 단위를 확정하지 않는다.
- 전일 대비는 현재가−전일종가로 계산한다. 등락률을 대조할 때는 공식 반올림 정밀도를 반영한다. 전일종가가 0 이하이면 계산하지 않는다.
- 화면의 조회 완료 시각과 API가 제공한 데이터 기준 시각을 구분한다. 체결 시각·거래 상태가 제공되지 않으면 추정하지 않는다. 캐시 결과에는 최초 조회 시각과 캐시 사용 여부를 표시한다.
- PER·PBR·EPS·BPS·배당수익률에는 KB증권 제공값이며 산식·기준일은 제공기관 기준임을 표시한다. 직접 계산한 값과 섞지 않는다.

[서버와 화면]
- GET /api/quote?symbol=6자리 를 만든다. 화면에 필요한 값과 출처·시각만 반환하고, 원본 응답 전체나 인증정보·IP·MAC은 반환하지 않는다.
- 형식이 잘못된 코드는 400, 공식적으로 종목 없음이 확인되면 404, 외부 API 장애는 502 등으로 구분한다. 연결 장애를 종목 없음으로 표시하지 않는다.
- 타임아웃, 호출 제한, 중복 요청 합치기와 짧은 캐시를 구현한다. 기업개요가 실패해도 정상적으로 받은 현재가를 유지한다.
- OpenDART 목록이 없어도 유효한 종목코드로 KB 시세를 조회할 수 있어야 한다.
- 인증 및 필요한 시세·기업정보 조회 경로만 허용한다. 계좌·잔고·주문·정정·취소 API는 연결하지 않는다.
- 지금은 종목코드로 조회한다. 회사명 검색은 다음 단계에서 추가한다. 출처는 KB증권 Open API로 표시한다.

끝나면 실제 조회 한 건의 화면 값과 같은 요청의 API 응답 값을 비교해줘. 인증정보는 출력하지 말고 비교 항목·일치 여부·확인 시각만 알려줘. 키나 권한이 없어 실행하지 못했다면 연결 완료라고 하지 말고 미확인 항목을 알려줘.
